# Systems & AI From Scratch

A collection of foundational systems, developer tools, and AI agents engineered completely from scratch.

## Projects Roadmap
- [x] **01-redis-clone-java:** Concurrent TCP server, RESP protocol parser, TTL expiration.
- [ ] **02-database-from-scratch:** Disk paging, buffer pool manager, B+ Tree indexing.
- [ ] **03-self-learning-ai-agent:** Reinforcement learning agent using Q-Learning / DQN.
- [ ] **04-private-search-engine:** Crawler, tokenization, inverted indexing, BM25 scoring.
- [ ] **05-c-in-c-compiler:** Lexer, recursive descent parser, AST, x86 assembly emitter.
